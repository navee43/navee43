## 🤖 Autonomous Coding Agent

An **Agentic AI-powered coding assistant** designed to understand programming tasks, generate solutions, execute code, identify errors, and iteratively repair solutions through a multi-step agent workflow.

### 🧠 How It Works

**Understand → Plan → Generate → Execute → Observe → Repair → Verify**

### ✨ Key Features

* Autonomous code generation and execution.
* LangGraph-based multi-step agent workflow.
* Tool calling with sandboxed code execution.
* Automatic error detection and iterative code repair.
* Multiple LLM provider integrations.
* Real-time execution updates.
* Docker-based isolated execution environment.
* Backend architecture using Node.js and FastAPI.

**Tech Stack:**
`React` `TypeScript` `Node.js` `FastAPI` `LangGraph` `LangChain` `MongoDB` `Docker` `OpenAI` `Groq` `Socket.IO`
